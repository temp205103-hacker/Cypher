SAFER BROWSING

Browser guard

The phishing guard is a browser extension that runs separately from this dashboard.

PG
CHROME & EDGE

Phishing Guard

Checks links on web pages against a locally cached community feed. Visited URLs are checked locally and are not sent to the feed provider.

  1. Open chrome://extensions or edge://extensions.
  2. Turn on Developer mode.
  3. Choose Load unpacked and select browser-extension\phishing-guard inside the project folder.
  4. Reload any tabs that were already open.
!
Coverage is limited

The extension checks page links, not every typed URL, external-app link, or redirect. It cannot catch every phishing attempt.
